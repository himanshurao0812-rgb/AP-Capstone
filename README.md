# TalkArena 🎙️
### AI-Powered Group Discussion Platform

TalkArena is a college project where friends can connect online, chat, join video calls, and discuss different topics together. The special feature of our platform is that AI can join the group conversation as another participant.

Whether you want to discuss movies, share theories, debate on a topic, or study together, TalkArena provides a common space for everyone.

## 💡 What is TalkArena?

Imagine you and your friends are discussing *Avengers: Doomsday*. Everyone shares their own theories, and when AI Mode is turned on, AI also joins the discussion, shares its ideas, asks questions, and gives different perspectives.

The same idea can be used for DSA discussions, coding problems, debates, and casual conversations.

## ✨ Features

- **Group Chat:** Create rooms and chat with multiple friends.
- **Video Calling:** Join discussions through video calls when you want.
- **AI Participant:** Let AI join the conversation and share its own ideas.
- **Study Mode:** Discuss DSA, coding, and other academic topics with AI assistance.
- **Debate Mode:** Discuss different opinions and get counterarguments from AI.
- **Movie & Game Discussions:** Share theories, discuss movies, and discover games.
- **AI Fact Checking:** Get help checking factual claims using reliable sources.
- **Room Controls:** Manage participants and help keep discussions safe.

## 📊 Data Engineering Part

Since this project is being developed for our Data Engineering course, we also plan to work on data processing and analytics.

- Collecting room activity and relevant application events.
- Storing data in PostgreSQL.
- Cleaning and processing data using Python and SQL.
- Creating pipelines to transform raw data into useful information.
- Analyzing popular topics, active rooms, and user engagement.
- Building a dashboard to display useful statistics.

## 🚀 How It Will Work

1. A user creates a discussion room.
2. Friends join the room using an invitation link.
3. Everyone starts chatting or joins a video call.
4. Users can turn AI Mode on when they want AI to participate.
5. AI understands the ongoing discussion and shares its own ideas.
6. Discussion data can be processed to generate useful analytics.
